PaperPress is a WordPress starter theme based on Underscores and intended to be extended into a custom theme rather than used as a parent theme.

  • Responsive: provides a flexible starting layout for multiple viewport sizes.
  • Developer-first: keeps the theme intentionally hackable and lightweight.
